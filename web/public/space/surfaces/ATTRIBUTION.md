# Planet surface maps

Textures by **Solar System Scope / INOVE**, licensed under **Creative Commons Attribution 4.0 International**.

- Author / original downloads: https://www.solarsystemscope.com/textures/
- License: https://creativecommons.org/licenses/by/4.0/
- Original maps are unchanged. Their placement on fictional book/chapter worlds is an artistic adaptation, not a physical solar-system model.
- The provider describes NASA imagery/elevation inputs, enhanced colors and fictional gap filling; these are visualization maps, not measurement data.

The origin host was not reachable from this build environment. Byte-preserving copies were obtained from these pinned, attributed mirrors:

- https://github.com/RTF22/Orrery/tree/6c81feb760cb36d7d83d1421aef257833ba9768e (maps and rings; see ASSETS.md)
- https://github.com/elymas/solar-simulator/tree/d34a9f973a7c4ad683eeb7d080b0accaba81e840 (Earth clouds; see README texture attribution)

No application code, other images or services from these mirror repositories are imported. Original and download URLs, byte counts and SHA-256 are recorded per file in `manifest.json`. All files are served locally at runtime.
