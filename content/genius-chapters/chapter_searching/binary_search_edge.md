# 二分查找边界

## 查找左边界

Question

给定长度为 $n$ 的有序数组 nums ，里面可能有重复元素。请返回数组中最左边那个 target 的索引；数组里没有该元素就返回 $−1$ 。

回想一下找插入点的做法：搜索结束后 $i$ 指向最左边的 target ，因此查找插入点本质上是在查找最左一个 target 的索引。

考虑通过查找插入点的函数实现查找左边界。请注意，数组中可能不包含 target ，这种情况可能导致以下两种结果。

- 插入点的索引 $i$ 越界。

- 元素 nums[i] 与 target 不相等。

碰到上面两种情况，直接返回 $−1$ 就行。代码如下：

## 查找右边界

那怎么找最右边的 target 呢？最直接的办法是改代码，把 nums[m] == target 时的指针收缩方向反过来。代码这里省略，有兴趣可以自己写。

下面我们介绍两种更加取巧的方法。

### 复用查找左边界

其实也可以借用找最左元素的函数来找最右元素，办法是：将查找最右一个 target 转化为查找最左一个 target + 1。

如下图所示，查找完成后，指针 $i$ 指向最左一个 target + 1（如果存在），而 $j$ 指向最右一个 target ，因此返回 $j$ 即可。

![将查找右边界转化为查找左边界](/genius/media/image_244.png)

请注意，返回的插入点是 $i$ ，因此需要将其减 $1$ ，从而获得 $j$ ：


### 转化为查找元素

我们知道，数组里没有 target 时，最后 $i$ 和 $j$ 会分别指向第一个大于 target 的元素和最右边一个小于 target 的元素。

因此，如下图所示，我们可以构造一个数组中不存在的元素，用于查找左右边界。

- 找最左一个 target ：可以转成查找 target - 0.5 ，然后返回指针 $i$ 。

- 找最右一个 target ：可以转成查找 target + 0.5 ，然后返回指针 $j$ 。

![将查找边界转化为查找元素](/genius/media/image_245.png)

代码在此省略，以下两点值得注意。

- 给定的数组里没有小数，所以不用操心相等的情况怎么处理。

- 因为引入了小数，函数里的 target 变量要改成浮点类型（Python 不用改）。
