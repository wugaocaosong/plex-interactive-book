# PLEX · 星轨编程 v0.3.0

新增 45 分钟原创教学单元「三扇舱门：直觉可靠吗？」：14 页串联故事、概率解释、Python 补学、真实批量实验、三道编程题、四题 H5P 自测及学习反思。保留完整教材和 v0.2 学习工具。

- 底部阅读导航、小E入口、桌面分栏和手机学习面板。
- 可重放的三门故事、同条件比较的 Python 实验、逐条记录与频率曲线。
- 按逻辑页保存的小黑板：绘画、文字、状态插图、撤销／重做及 PNG 导出。
- 访客与 PLEX 账号分开的本机记录，兼容旧备份，令牌不进入备份。
- 对接既有 PLEX 登录、画像、版本核对、正式提交和可恢复／取消的辅导；真实模型与规则提示明确区分。

完整 ZIP 包含源码、依赖锁、全部教材与运行资源、静态成品、启动脚本及技术／教学／验收文档。解压后安装 Node.js 24+，双击 `START_PREVIEW.cmd`，或运行 `node scripts/serve-dist.mjs`。本机学习无需安装 npm 依赖；源码开发和重建步骤见 `docs/REPRODUCIBILITY.md`。

默认 `/api` 代理连接 `http://127.0.0.1:5100`。设置 `PLEX_API_TARGET=off` 可关闭在线功能；其他地址必须是受信任的固定后端来源。接入与三题增量导入见 `docs/PLEX_INTEGRATION.md`。

验收详情见 `docs/VALIDATION_V03.md`。真实课堂试用及 NVDA／VoiceOver 人工验收仍待完成。发布保持私有，不自动公开部署。

附件 `.zip.sha256` 校验完整压缩包；包内 `PACKAGE-MANIFEST.json` 列出源码提交和逐文件校验值。
