2. 手机搜索浮层限制在标题区域宽度内，避免左侧溢出。
3. 跨小节搜索等待目标排版完成再高亮；重新聚焦输入框可继续查看当前结果。
4. 搜索浮层打开时，统一翻页入口不响应背景翻页；Escape 可关闭浮层。
5. 预设知识关联与实际模型检索分别标识。模型失败时可以切回精确查找。

## 操作入口

阅读页顶部输入框或“更多 → 搜索全书”。精确查找显示文本片段，点击跳转并高亮；“上一个／下一个”切换匹配位置。AI 模糊查找先提供已配置的概念关联，再按需加载浏览器内模型。
