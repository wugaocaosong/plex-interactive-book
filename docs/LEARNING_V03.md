# v0.3 三门问题教学单元：实现与维护

本版在 v0.2 阅读器前增加 14 页原创教学单元「三扇舱门：直觉可靠吗？」，全书共 143 个逻辑小节：118 个固定版本教材页面、11 个原有 PLEX 附页、14 个新页。逻辑页不等于物理页，字号和屏宽仍决定分页。没有导入第二本完整教材。

## 教学材料与入口

逐页原稿、三道题及四道概念题集中在 `content/learning/monty.py`；完整模拟程序在 `content/learning/monty-simulation.py`。`import:book` 读取这些材料生成稳定路由和内容块；`build:learning` 生成单元定义、练习及可编辑程序；`build:activity` 生成两套 H5P 参数，再复用已校验的 9 个运行库。新增材料不写入上游来源目录。教师可从 [45 分钟逐页脚本](LESSON_MONTY.md) 备课。

阅读主操作位于底部。目录包含学习起点；更多菜单包含模式、笔记、搜索、设置、全屏、原有六类实验及 24 题。书页中的活动入口打开 `UnitPanel`，底部小E直接打开辅导页。编辑器、H5P 和板书都在 StPageFlip 外；桌面两种阅读模式均可在单元活动旁阅读，手机使用独立对话框。关闭后从原内容定位恢复。

## 概率模型与真实执行

`monty-hall.ts` 是故事的纯状态模型，规定合法开门、换门、种子、预测和历史；回看只切换观察步骤，不重新抽取奖品。下一轮才提交历史。最多保留最近 200 个故事结果。

理论值来自加权枚举全部初选、奖品和主持人合法动作；测试证明不换门 1/3、换门 2/3，不通过“随机结果恰好接近”验收。故事明确标注教学演示。

批量模拟在模块 Worker 内用 Python `random.Random(seed)` 生成实际记录，两种策略共用每轮条件。返回值经过次数、种子、合法门状态、获奖判断及汇总一致性检查，曲线从记录重新累计。10、100、1000、10000 次都可复现，最多显示 400 个曲线采样点，回放与导出保留全部记录。程序或设置变化后，旧结果明确标为上次运行；失败不会伪造新曲线。不是任意 Python 程序的逐行追踪器。

初始化限时 90 秒，执行限时 10 秒，停止与超时终止 Worker，运行编号过滤迟到消息。原有自由运行、独立判题 Worker 和 73 个教材示例继续保留。

## 学习证据与达成标准

三道新练习共 18 个用例，与原有 24 题的 112 个用例一起审计。H5P 为四章各一道单选题，保存每题得分、总分及原生状态。单元达成依据三道练习最近一次完整测试全部通过、自测至少 3 分、第一道规则题正确；阅读、故事获奖、提示次数和试验次数不作为掌握证明。

服务器判题使用 PLEX 已有表达式执行模式。受控表达式比较 `solve(*args) == expected`，避免原有 stdout 字符串判题把数值相等的 `1` 和 `1.0` 判错。详细输入、期望与实际值仍由本机练习界面展示。正式在线作答与本机检查分别记录。

## 本地数据与账号边界

保留原 `plex-learning` IndexedDB，不破坏 v0.2 数据。访客继续使用原键；账号记录添加 `user:<id>:` 前缀。阅读设置、位置、书签以及 H5P 的 localStorage 镜像使用相同命名空间。旧版迁移仅在访客运行，保留原键，可重复执行。登录后主动复制访客记录，冲突两个版本分别保留。

范围在文档生命周期内固定。登录、退出、切换账号先等待已挂载组件保存，再更新独立 sessionStorage 会话并刷新；旧组件的晚到写入仍指向旧空间。令牌和密码不写入 IndexedDB、不导出到学习备份。退出不可用时提示服务端会话撤销未确认。本机账号隔离不是设备级加密，使用共享电脑仍应自行保管导出的学习文件。

备份格式升级为 version 2，兼容 version 1。包含实验、板书、反思、练习与原有学习记录；导入先验证再预览数量，处理冲突的 H5P 镜像也按账号隔离。记录字段见 `types.ts`、`unit-types.ts`、`monty-hall.ts`。

小黑板采用 SVG 矢量对象：笔画、文字、当时的三门快照。按逻辑小节保存，缩放不改变坐标；撤销包含清空，支持 40 步会话历史、最多 300 个对象，每笔最多 4000 点。PNG 由本机 SVG 绘到 canvas 导出。文字输入和插入状态图为不能使用画笔的读者提供替代方式；自由绘画本身仍需人工无障碍评估。

## PLEX 连接

接入基线为 PLEX 主工程 `536ac132f35dfff88f97bc85f1515a77d405b153`。没有依赖旧工作树的循环专用接口，也没有增加云端笔记同步。配置、增量题库导入和复验见 [PLEX 接入指南](PLEX_INTEGRATION.md)。

客户端核对服务端题目版本，提交取得作答编号。报错模式还执行绑定代码和题目的服务器自测，取得运行编号；浏览器成绩不会作为真实作答证据发送。辅导支持恢复、取消、限额／失败提示；只有 `generation_mode=llm_reviewed` 标为在线模型，其余规则提示或未完成状态另行标注。
