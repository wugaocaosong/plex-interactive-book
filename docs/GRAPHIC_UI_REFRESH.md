# 全书图形化 UI 更新

日期：2026-10-29。基于用户确认的 PLEX IP / 小E壁纸与中央浮窗效果图实施。沿用 `codex/ch12-learning-demo`，本轮为全书界面更新，不修改教材编排或新增第 13—16 章教学活动。

## 实际变化

- 全书使用本地青蓝壁纸，叠加深蓝遮罩：主体区域约 42%–79% 遮光，底部进一步压暗。原图保持原样；封面、阅读、目录和工具使用同一套环境。
- 首页保留原书封面与拖动开书，增加 IP 背景和引导文案。导航、弹窗标题、按钮使用青蓝/黑白、切角、错位边框和粗体标题；长篇正文仍用独立纸面。
- 全部活动改为中央浮动窗口，包括全书代码、图解、学习实验室、三门单元、小E、小黑板及第 12 章任务。桌面不再显示侧栏；手机使用留有外边距的大窗口。支持放大/还原，操作不会重新创建活动实例。
- 打开活动不修改书页尺寸或重新分页。背景正文与导航进入 inert 状态；焦点约束在窗口中，Escape/关闭恢复触发位置。需要翻书时先关闭窗口，活动记录、代码草稿仍按既有机制保存。
- 目录、搜索、笔记、书签与设置共用新视觉。笔记和学习实验室标题区域分别使用压暗的紫红、红黑壁纸。H5P 自身内部控件、绘画内容与算法颜色语义保持其功能样式，外部播放器窗口统一。
- 浅色/深色/跟随系统、字号与阅读宽度继续可用。旧备份中的分栏比例字段仍保留兼容，但当前 UI 不使用它，不需要迁移数据库。

## 实现与资源

视觉入口为 `web/.vitepress/theme/phantom.css`，放在原样式之后导入；正文相关规则同时作用于测量区和实际书页。浮窗行为在 `Layout.vue`；窗口没有放入 StPageFlip 克隆区域。

三张生成壁纸在 `web/public/brand/wallpapers/`，构建时直接复制到静态站点。来源与哈希见同目录 `SOURCES.json`。它们来自用户提供的角色三视图、项目小E素材与内置图像生成工具，不包含第三方游戏截图、角色或 logo。原图的亮度通过 CSS 控制，没有覆盖生成原件。

新增使用已锁定的思源黑体 700 字重，未添加运行依赖。全部壁纸和字体本地加载；普通入口只请求青蓝背景，紫红/红黑在对应窗口出现时加载。

## 验证方式

```sh
npm run check
npm run build
npm run test:e2e
node scripts/serve-dist.mjs --port 5190
```

`tests/browser/visual-theme.spec.ts` 覆盖 390/820/1440px 的封面、底部导航、目录/工具焦点、两种阅读模式的窗口位置、放大还原、正文宽度/位置、关闭恢复及 axe。原分栏测试按新的中央弹窗要求调整；三门活动跨页测试改为先关闭、翻书，再打开，确认预测草稿仍在。

原始浏览器日志和截图保存在本机 `output/`；最终通过数量和全书分页结果见本轮验收记录。屏幕阅读器人工验收、真实触屏与课堂试用需另行进行。

## 回退

本轮不覆盖固定来源快照，不重新导入教材，不改稳定块 ID。回退本次提交可恢复旧 UI；不要清空浏览器学习数据。不能只删除样式而保留新的窗口结构，也不能删除已有壁纸引用却保留 CSS。
