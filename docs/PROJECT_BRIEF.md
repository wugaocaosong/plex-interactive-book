# 项目简述

《PLEX · 星轨编程——Python 与算法的探索之旅》是独立的交互式数字教材。正文采用固定版本《Hello 算法》简体中文版，保留完整内容、代码与图解；PLEX 提供封面、编排、原创附页、星域导航和动手练习。

首版技术为 VitePress + Vue + TypeScript、StPageFlip、H5P Interactive Book / Standalone、Pyodide。配色为 `#131315`、`#F7EEDB`、`#242723`、`#4F8D86`、`#D9B873`。封面保留用户附件完整比例，星图使用原作独立素材。

顺序：封面 → 扉页 → 版权 → 献辞 → 编者前言 → 原序 / 第 0 章前言 → 目录 → 学习起点与三门问题（14 页） → 第 1—15 章 → 后记 → 致谢 → 第 16 章附录 / 参考文献 / 索引 → 作者与编者 → 封底。

交付本地运行应用与静态构建，不公开部署。默认简体中文、全语言代码、Python 优先、本机进度；班级管理、编辑后台、全书新增题库、EPUB / PDF 导出不在本轮范围。

命令与验证见 [README](../README.md) 和 [架构说明](ARCHITECTURE.md)。

v0.3 已复用现有 PLEX 学生登录、画像、正式提交和小E辅导；仍不新增账号体系或本机学习数据云同步。
