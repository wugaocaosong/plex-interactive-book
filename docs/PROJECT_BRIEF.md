# 项目简述

## 定位

PLEX 延伸的编程入门数字教材：《星轨编程——Python 与算法的探索之旅》。围绕电子书的内容创作、阅读和交互开发。

## 内容与交互

正文计划沿用 Hello 算法原文，重点呈现 Python 示例。交互作为正文旁的增强层：算法执行过程、逐步演示、参数调整、代码运行和章节练习。正文导入时记录对应上游路径、固定提交版本及本地改动。

## 视觉参考

- `assets/references/cover.png`：用户提供的书籍封面。黑色背景、暖白文字、青绿色宇航员、月牙和轨道。
- `assets/references/star-map.png`：用户提供的星域导航截图。以行星呈现章节，通过轨道串联知识主题。

参考图仅作设计输入；来源和使用权记录见该目录的 README。

## 后续实施顺序

1. 确定章节结构，建立 Hello 算法正文与资源的可追溯导入流程。
2. 实现封面、目录、章节阅读与响应式排版。
3. 完成一个章节的交互演示与 Python 代码运行体验。
4. 扩展书签、阅读进度、练习与更多章节。

## 初始化边界

此阶段只建立仓库、说明和资源结构。框架、代码执行方案与发布方式尚未定案。
