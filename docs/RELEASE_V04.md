# PLEX · 星轨编程 v0.4.0

深化 45 分钟样板课《三扇舱门：直觉可靠吗？》，保留 14 个稳定逻辑页、118 个教材页、27 道编程练习、两套 H5P，以及原有双模式阅读和学习记录。

- 每页目标、对应活动、小E短提示与下一教学环节相互联动；普通翻页保留当前活动。
- Motion for Vue 二维舱门、核心与小E动作；可跳过动画，尊重减少动态效果设置。
- 规则判断、三个等可能核心位置的枚举及分步解释；首次预测与理由独立保存。
- 三个不计分 Python 补学示例、真实单次试验及四档批量试验；ECharts 保留所有累计频率点和固定理论线。
- Rough.js 固定种子的矩形、圆圈、箭头和概率分组模板，支持保存、撤销和 PNG 导出。
- 学习报告预览、Markdown／独立 HTML 下载及浏览器打印 PDF；不导出账号或在线对话。
- 备份 v3 兼容 v1/v2，旧数据不补造首次理由和完成时间。原有 PLEX API、题目身份及服务端版本核对保持不变。

完整 ZIP 包含源码、锁文件、全部静态运行资源、教学脚本、启动脚本和技术／验收文档。解压后使用 Node.js 24+ 双击 `START_PREVIEW.cmd`，或运行 `node scripts/serve-dist.mjs`，打开 `http://127.0.0.1:5190/`。运行分发包不需要 `npm ci`、Python、数据库或外站资源；源码重建见 `docs/REPRODUCIBILITY.md`。

默认 `/api` 连接本机 PLEX 后端 `http://127.0.0.1:5100`；通过 `PLEX_API_TARGET` 配置固定来源，或设为 `off` 关闭在线功能。后端离线时阅读、本机 Python、活动和报告继续可用。

校验完整 ZIP 使用附件 `.zip.sha256`；包内 `PACKAGE-MANIFEST.json` 记录提交号和逐文件 SHA-256。发布附件另含最终解压验证记录，避免把归档自身的哈希循环写入归档。

验收证据见 `docs/VALIDATION_V04.md`。真实课堂教学试用和 NVDA／VoiceOver 人工验收仍待完成；固定 Vue/VitePress 依赖的已知公告在文档中保留。v0.3.0 继续可回退，本版保持私有，不公开部署。
