## 真实模型与模拟输入的区别

- **真实 Vosk 推理**：将 Windows 本机合成的“下一页”PCM 音频送入真实 AudioWorklet 和本地 Vosk 模型，识别后关闭设置并触发下一页，验证停止后媒体轨道结束。
- **真实手部推理**：将官方手部图片绘制为合成摄像头视频帧，先识别双手并拒绝翻页，再以单手平移序列触发下一页，验证失去焦点后轨道释放。这不是实体 USB 摄像头或真人挥手校准。
- 以上测试拦截所有非 localhost/127.0.0.1 请求，实际外站请求为 0。MediaPipe 输出的 `Created TensorFlow Lite XNNPACK delegate for CPU` 是其初始化信息，不是检测失败。
- **确定性逻辑测试**：另行注入关键点轨迹、识别文本和按键事件，覆盖方向、抖动、回手、双手、闭手、冷却、重放、普通词和方向冲突；不把这些模拟测试称为模型识别成功。

首次模型接入发现并修复了 Vosk 归档目录权限导致的缓存错误、MediaPipe 的模块 Worker 加载器兼容问题。失败过程未计入通过结果，最终资源格式与 Worker 方案见实现文档。
