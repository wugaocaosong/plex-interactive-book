## 浏览器覆盖及复验说明

完整回归首先执行了 78 项测试：77 通过，1 失败。失败项是新增账号隔离测试错误地假设新账号继承访客的连续阅读模式；产品实际按约定使用新账号默认翻书模式。修正测试后，该场景通过。

随后补充手机保存失败与模式切换测试。新增 10 项测试分批复验：4 项功能测试通过，6 项尺寸/模式测试曾报告汉诺塔按钮可见数字与辅助名称不匹配。修正按钮名称后，最后一轮 6 项全部通过。最终为 **69 项原有测试 + 10 项新增测试均有通过结果**，不是宣称最后一次单次全量运行了 79 项。

新增测试覆盖：

- 三尺寸、翻书/连续阅读两模式下的任务路线、实验打开关闭、输入与步骤恢复；拆分合并和汉诺塔面板 axe 检查无违规。
- 汉诺塔合法/非法手动移动、标准解、移动计数、可见环尺寸；拆分合并重复数、负数、输入限制。
- 整章首次术语、悬停固定、手机边缘定位；批注创建、编辑、草稿、快捷键、刷新及模式切换。
- 注入 IndexedDB 写入失败，确认保存错误明确显示、文字保留且重试后成功。
- 五道任务真实 Python 判题、源码信息折叠展开、保留原始作者头部。
- JSON 备份导出/导入、实验状态恢复、新账号隔离及凭据排除。

本机原始报告位于忽略的 `output/ch12-browser-results.json`、`output/ch12-final-browser-results.json`、`output/ch12-layout-final.json`；分页报告位于 `output/validation/`。测试源码已入库，可重复运行，不要求交付这些较大的临时日志。

## 复现

先按 `REPRODUCIBILITY.md` 安装依赖，运行：

```sh
npm run import:book
npm run check
npm run build
node scripts/serve-dist.mjs --port 5190
```

入口：`http://127.0.0.1:5190/read/chapter_divide_and_conquer/index`。

浏览器验证使用 `npx playwright test tests/browser/chapter12.spec.ts`；全书回归使用 `npm run test:e2e`。本机使用系统 Chrome，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定浏览器路径；临时测试预览使用 `PLEX_TEST_PORT=5194`、`PLEX_TEST_PREVIEW=1`、`PLEX_TEST_REUSE=0`，避免干扰 5190 的验收服务。
