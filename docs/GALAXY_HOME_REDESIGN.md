# 漫画银河与实体书入口

日期：2026-11-02。功能分支：`codex/galaxy-reading-upgrade`。本轮仅修改书库与开书入口，未改 PLEX 后端、教材正文或 main。

## 使用

打开 `/` 进入星轨书库。拖动观察银河，滚轮靠近；点选 PLEX 星球或它的名称，镜头推进后出现实体书。其他六颗星球为待上架席位，不提供虚构内容。左下“书籍导航”提供键盘可用的文字入口。

书籍观察界面可按住拖动旋转、滚轮缩放；手机可单指旋转、双指缩放。方向键旋转，Home 或“回正”恢复正面。封皮、书脊、封底、纸块和扉页是独立几何体；只有正面封皮的短点击进入阅读，拖动超过 6px 或点击背面不进入。也可使用“开始探索”按钮。

封皮沿左侧书脊展开约 0.7 秒，画面约 0.25 秒渐暗，在真实书页加载完成后短暂停留约 0.2 秒，再用上下曲线遮罩约 1.2 秒揭幕。不是人脸或真实眼睛动画。加载异常可重试或返回银河；黑场覆盖期间背景不可交互，键盘焦点留在转场控件中。

“继续探索”直接恢复原小节与锚点，不重复播放入场。既有 `/read/...` 深链接保持直达。返回银河恢复本次观察相机。简化显示可手动切换，减少动态效果默认使用简化显示；WebGL 创建失败或上下文丢失自动降级。退出首页释放几何、材质、纹理、烘焙目标、控制器和渲染器，后台停止帧循环。

## 来源与实现

已拉取 [Galaxy Explorer](https://github.com/zjoooooo/galaxy-explorer)，固定提交 `2df71512c45e6de15a50f5e36dfd5dbe5e462ecd`，MIT，原作者 Justin Zhang Jun。复用和改编 `index.html` 的 `buildDust`（约 689—742 行）和 `buildPaintedGalaxy` 中的 GLSL（约 784—829 行）。完整许可位于 `licenses/galaxy-explorer-MIT.txt` 并随构建提供。

改动包括固定随机种子、世界坐标缩放、青紫配色、定义合法的 smoothstep 边界、4 层噪声、每方向 6 步的流向卷积和低分辨率一次性烘焙。没有引入旧版 Three、太阳系、外部摄影、音乐或数据 API。

当前 `GalaxyScene` 使用现有 Three.js 0.187.0 的单一 WebGLRenderer 管理场景，相机交互使用同版本 OrbitControls。TresJS 5.10.0 依赖继续保留；本次替换了旧 TresCanvas 包装和叠加的 CSS 大球，避免两个渲染器分别处理星球与书。没有新增 npm 依赖，锁文件版本保持不变。

几何与星球表面程序生成，书籍正面直接使用原封面；封底和书脊通过本地 Canvas 绘制。已确认的三张概念稿保存在 `docs/design/galaxy-home-2026-11-02/`，不会把整张效果图铺成伪交互背景。实际效果是实时 WebGL 场景，依赖现有设备性能。

## 性能预算与兼容

| 初始视口 | 银河粒子 | 背景星点 | 银河底图烘焙 | DPR 上限 |
|---|---:|---:|---:|---:|
| 小于 700px | 6,500 | 450 | 512×512 | 1.25 |
| 其余 | 18,000 | 1,000 | 1024×1024 | 1.5 |

渲染模块按首页懒加载。全部运行资源来自本机站点，无外部纹理或 CDN；首屏底图只烘焙一次，后续使用纹理。生产构建仍有既有依赖块大于 500 kB 的提示，不阻断构建。实际设备的低功耗、触控和屏幕阅读器体验需人工验收，自动浏览器测试不能替代真机。
