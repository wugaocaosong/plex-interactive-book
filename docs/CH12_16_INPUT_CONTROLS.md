# 第 12—16 章输入控制约定

更新：2026-10-30。状态：三种控制已实现，硬件校准仍待用户真机验收；操作和技术说明见 [实现说明](INPUT_CONTROLS_IMPLEMENTATION.md)。

## 已确认需求

- 手势翻书采用摄像头识别隔空手势，不是触屏滑动。提供显式开启、关闭、识别状态和识别后的翻页反馈。
- 翻页笔通过 USB 接入，采用键盘事件映射。用户已说明设备插入；实际发出的 `key/code` 尚待页面接收并确认，不根据 USB 接入推断按键。
- 语音向前翻页关键词：上、前；向后翻页关键词：下、后、翻页。完整短语如“上一页”“向前翻”“下一页”“向后翻页”也按对应方向解释。
- 上述输入统一使用阅读器现有上一页/下一页入口，保持跨小节导航和阅读位置服务兼容。

## 实现与验收约定

1. 摄像头和麦克风分别按需开启，由浏览器请求权限；关闭后释放设备。摄像头方向、阈值和冷却时间需用真实设备校准。
2. 翻页笔提供按键检测与映射入口；优先检查设备实际输出，再保存上一页/下一页配置。不能只凭设备已插入就显示“连接成功”。
3. 语音按一次有效识别结果触发一次翻页，临时结果和重复回调不重复触发；优先匹配明确方向，单独“翻页”表示下一页，同时出现冲突方向时不执行并提示重说。
4. 单字关键词会有误触发风险，使用明确的监听状态、可关闭入口和翻页冷却；不在输入框、代码编辑器、批注编辑或活动弹窗操作期间翻动背景书页。
5. 摄像头手势、USB 按键、语音与鼠标/键盘按钮分别验收；权限拒绝、设备断开或识别不可用时仍能正常阅读。
6. 语音已选择并实现 Vosk 本地中文模型，不调用浏览器云语音服务；模型测试与用户真实设备测试分别记录。
