# 动态星系与 Q 版小E

功能分支：`codex/galaxy-particles-chibi-pet`；基线为 main `1dbd61e490bd67cb15335abb97a5ad5f11875d12`。本轮没有部署线上站点，也不合并 main。

## 使用入口

1. 首页 `/` 选择 PLEX 恒星系。其他六个席位只有“待上架”状态，不包含教材。
2. 查看立体书：拖动旋转，回正，点击正面或“开始探索”。封皮展开、黑场与睁眼结束后进入 `/library/plex-programming/contents`。
3. 点选章节星体或文字卡片进入章节。悬停／聚焦暂停目标；可暂停全体公转或切换简化显示。第 16 章为附录；页面下方完整编排保留全部附页。
4. 阅读器的目录复用同一组件；关闭目录回到原书。继续探索与原 `/read/...` 地址直接阅读，不重播入场。
5. 小E浮于页面边缘。角色附近的设置按钮可调整 70%—200% 大小、随机动作和默认尺寸，缩放把手支持拖动与方向键。隐藏后通过首页、目录页“显示小E”或阅读器“更多 → 显示小E”恢复；代码窗口召唤也会恢复。

## 实现与资源

- `GalaxyEngine` 继续复用固定提交的 Galaxy Explorer 底图与星尘算法；差速星尘在 GPU 着色器中运动。七个真实三维恒星系包含恒星、三条轨道和各自环绕星体。
- `GalaxyEffects` 使用精确版本 `three.quarks` / `quarks.core` 0.17.1：汇聚、彗星拖尾、点选喷发配合扩张环。桌面强喷发 600 粒子、手机 180；普通反馈 180/70。发射冷却 180ms、瞬态最多四组、1.9 秒后回收，常驻彗星与汇聚独立限量。所有纹理由本地 Canvas 生成。
- `SolarEngine` 从教材 manifest 选择章首页，不另建一套目录。16 章分配四条示意轨道，不代表真实天文比例。文字按钮保留触屏、键盘与 WebGL 降级路径。
- 银河背景星尘桌面 18,000、手机 6,500。每四秒采样帧间隔，低于桌面 43fps／手机 27fps 时降低像素比与银河星尘量；太阳系同样降低像素比。后台暂停，切换场景释放几何体、材质、纹理、监听器与渲染器。减少动态效果默认静态／简化模式。
- 小E来自新生成的精绘透明图集，通过 SVG 独立裁取头部、面屏、躯干、手臂、脚、天线及光屏，眼睛与嘴部单独绘制。并非整张图左右摇摆。六姿态预览与图集见 `web/public/brand/chibi-e/`；提示词摘要、SHA-256 见 `SOURCES.json`。
- `AppLayout` 只创建一个角色宿主。银河、目录、正文切换只更新阅读上下文；拖动、思考、答复、失败和随机闲置动作由真实状态驱动。闲置间隔 10—25 秒且不连续重复；拖动优先，后台、隐藏和减少动态效果停止随机动作。

## 数据与兼容

新增本机记录 `pet:appearance = {version:1, scale, visible, idleMotion}`，纳入已有账号命名空间和版本 3 JSON 备份，不升级 IndexedDB。旧数据使用默认外观；原草稿、位置、批注、书签、教材与智能搜索不改格式。隐藏先保存草稿，并停止录音和未完成请求。角色设置不会改变聊天字体。

本轮未新增后端接口。源码／模型答疑与离线听写沿用原接口。新增画面资源不请求外站；已有智能搜索首次下载 Hugging Face 模型的限制仍然存在，不能据此宣称全产品首次启动完全离线。

## 本地复现

要求 Node.js 24+ 与 Python，使用锁文件安装：

```powershell
npm ci
npm run check
npm run build
npm run dev -- --port 5196
```

开发预览 `http://127.0.0.1:5196/`；生产预览可用 `npm run preview -- --port 5197`。模型、播放器、字体与新图集都由现有 assets/build 流程携带。不要提交 `node_modules`、输出截图或测试缓存。

### 性能采样与限制

在本机 Intel UHD Graphics / ANGLE D3D11 的无头 Chrome 中，每场景停留 8.5 秒，读取连续四秒的 rAF 采样：

| 视口宽度 | 银河 rAF/s | 章节目录 rAF/s |
|---|---:|---:|
| 390 | 152.0 | 151.8 |
| 820 | 164.8 | 153.5 |
| 1440 | 147.1 | 157.0 |

这些是无头环境的渲染循环采样，**不是屏幕实际显示帧率，也不是手机实测**。采样均保持丰富画质；自动降级阈值为桌面 43／手机 27 rAF/s。轨道按钮避碰是在上述性能采样后加入的轻量布局，真机的持续 60fps／30fps 目标仍需在最终设备验证，不以此表代替。验收截图和原始日志在本地 `output/stellar/`，该目录按仓库约定不提交。

模拟 PLEX 接口只用于请求状态回归，不代表真实在线模型联调；本轮没有改变后端。USB 摄像头／麦克风／翻页笔的真机操作、低端手机持续性能、屏幕阅读器与人工教学试用列为待人工验收。
