# 可移动小黑板、角色助手与翻页笔全屏

更新日期：2026-10-30。分支：`codex/ch12-learning-demo`。

## 使用入口

- 底部导航“小黑板”直接打开画板，不经过学习活动页面；“更多 → 本页小黑板”和三门实验的板书入口也打开同一浮窗。
- 拖动浮窗标题栏移动，拖动右下角缩放。标题栏和缩放按钮获得焦点后也能用方向键操作；Shift 加快移动。
- 每个教材小节最多 10 块画板，支持命名、切换、新建、删除及恢复最近删除的画板。窗口打开后固定在打开时的小节，翻书不会替换其内容；关闭再从新页面打开会使用新页面的画板。
- 底部原小E入口改为小黑板。页面内的正面机器人“小艺（PLEX 小E）”可以拖动；点击打开聊天气泡，再次点击或关闭按钮收起。
- “更多 → 翻页控制 → 录入全屏切换”：按翻页笔发出的键并确认。阅读时同一键第一次进入全屏，再按退出。Escape 仍可退出。录入区只测试，不执行全屏；与前后翻页映射冲突时拒绝保存。

## 基本绘画

画笔、对象橡皮、矩形、圆圈、箭头、颜色快捷按钮、自选颜色、1–40 的笔粗、12–120 的字号、可移动的多行文字框、图片插入/缩放、对象复制/删除/置顶/置底、撤销/重做、可撤销清空以及 PNG 导出。

选择工具可拖动文字、图片、笔画或图形，方向键微调；Shift + 方向键移动 10 个画布单位。文字框在上方编辑区修改后点“更新文字”。画布尺寸可以单独设置（320–2400 × 240–1800），调整尺寸不会删除画布之外的对象，恢复尺寸可再次查看。

快捷键仅在画板获得焦点、且没有编辑输入框时生效：1–6 换色，B 画笔，V 选择，E 对象橡皮，T 文字，R 矩形，O 圆圈，A 箭头，Ctrl/⌘ Z 撤销，Ctrl/⌘ Shift Z 重做，Delete 删除选中对象。三门状态图和概率模板保留在折叠的“画布尺寸与快捷键”中。

图片支持 PNG/JPEG/WebP/GIF，单文件不超过 5 MB。导入时在浏览器中转为本地 PNG 数据，GIF 作为静态图导入；拒绝 SVG 和远程 URL，避免导出时外站请求或活动内容。每块画板最多 300 个对象、40 个撤销步骤。PNG 导出为当前画板完整尺寸，包含本地图片、文字与图形，不含选中框。它是轻量画板，不是 Windows 画图应用的逐项克隆（无魔棒、像素级选区、滤镜或复杂图层面板）。

## 助手和离线语音

- 正面素材基于原项目 `little-e.png` 背面图生成，保存为 `web/public/brand/little-e-front.png`；来源与 SHA-256 见同目录 `SOURCES.json`。
- 动作为 CSS 待机浮动、悬停招呼、思考/聆听摇摆；尊重系统减少动态效果。不是骨骼动画或口型同步。
- 普通聊天复用 PLEX `/api/v1/student/messenger/chat`，发送 `{message, history}`，当前小节标题及标识包含在可见的上下文中；最多发送最近 18 条对话，不携带本机测验成绩。返回读取 `{reply, source}`，模型回复、服务端规则提示和未标注来源分别展示。
- 接口核对来源：本机 PLEX 工作树提交 `73b4beca3f9d65999e814aa317d58dc963afdad3`，`backend/app/routes/student_progress.py` 和 `backend/app/services/messenger_chat.py`。未修改 PLEX 后端。现有编程练习中的 `PlexCoach` 及正式提交/题目版本核验接口保持原行为。
- 必须已有 PLEX 学生会话，未登录提供登录入口。后端离线/未实现该聊天接口时，气泡明确显示错误且保留输入，不生成假回复；停止等待只取消本机请求，不宣称服务端已停止推理。
- 点击“语音输入”才申请麦克风，复用本机 Vosk 中文模型与 AudioWorklet。最终识别结果逐句填入输入框，临时结果只作预览。用户确认后点击发送，录音从不上传、不保存。没有登录也能转文字。
- 语音输入开始时停止语音翻页监听，避免同一段语音同时作为聊天和翻页命令；识别到“下一页”也只写入输入框。关闭气泡、页面失焦、后台、卸载或会话失效时停止并释放麦克风。中途未完成的临时识别不写入草稿。
- 草稿和角色位置使用原账号命名空间。聊天记录只保留在本次页面内存，不进入 JSON 学习备份；草稿会随学习备份保存。密码和令牌继续只在原会话存储中。

## 数据兼容与实现

旧 `blackboard:<sectionId>` 的 version 1/2 文档首次打开时转换为 version 3 工作区，所有原对象放入第一块画板，包括三门场景和 Rough.js 固定种子。保存沿用原记录键，不新增数据库。备份仍使用现有格式 3，校验器新增工作区/对象边界及内嵌图片白名单；旧备份仍可导入，冲突版本继续保留。旧客户端不能读取新版画板工作区。

`Blackboard.vue` 是唯一画板宿主；`FloatingToolWindow.vue` 处理位置/大小与键盘操作；`EbookPet.vue` 处理角色、气泡、聊天和离线听写。打开画板或聊天时外部翻页指令暂停，防止绘画/输入误翻；普通阅读导航仍可操作。打开传统模态活动时浮窗隐藏并退出焦点，关闭后恢复。

所有新资源本地打包，没有新增 npm 依赖。运行 `npm run dev`，开发地址 `http://127.0.0.1:5190`。检查 `npm run check`，生产构建 `npm run build`。本机浏览器验收可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定系统 Chrome。
