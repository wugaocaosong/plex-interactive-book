## PLEX：真实联调与模拟测试分开记录

接入主工程提交 `536ac132f35dfff88f97bc85f1515a77d405b153`，合同文件哈希在 `integration/plex-manifest.json`。没有修改 PLEX 源码或数据库结构。

1. **模拟契约测试**：独立临时 SQLite，验证登录、刷新、画像、增量导入幂等、版本冲突、重复提交、辅导恢复／取消及模型失败分支。执行器与模型的模拟结果不作为真实判题或模型联调证据。见 `v03-plex-contract-integration.json`。
2. **真实后端与 Docker 判题**：独立临时 SQLite，经真实 PLEX 应用，三道参考解法全部通过，三个错误起始程序均被拒绝；重复请求不重复记分，旧版本被拒绝。使用既有 `plex-python-sandbox:1` 镜像。见 `v03-plex-real-integration.json`。
3. **真实模型**：一次“只提示下一步”请求返回 `llm_reviewed`，通过 schema、行号范围、引用白名单及语义检查。强制模型失败验证没有冒充在线模型。此证据只说明本次请求成功，不声称所有提示模式或未来服务请求必然成功。
4. **浏览器真实 HTTP 链路**：通过静态预览服务的固定代理完成登录、画像、参考答案提交、错误代码提交和绑定运行记录的报错辅导。该次报错辅导未通过模型审核，返回服务端规则提示；界面正确标为“非模型生成”。见 `v03-plex-browser-real.json`。
5. **前端模拟接口**：覆盖离线、过期刷新、429 限额、题目版本变化、重复 UUID、取消、访客／两账号切换及备份排除令牌。真实后端联调与这些路由模拟断言分别保留。

本机 PLEX 数据库仅注册三个自有题目，稳定别名为 `MH030001`、`MH030002`、`MH030003`；重复导入均为无变更。别名遵守既有 MySQL 字段 8 字符上限。发布包不包含数据库、学生密码、会话令牌或模型密钥。

## 已知边界与待验收

- 45 分钟课堂试用、教学难度和时间分配需要教师与学生实际验证。
- NVDA／VoiceOver 人工走查未完成。自动化覆盖键盘、对话框和文字替代，不能替代屏幕阅读器实测。
- 干净构建在 Windows 验收；其他系统有启动说明，尚未声称实测。
- 账号、画像、正式判题和真实模型需要另行运行兼容 PLEX 后端、Docker 执行器及配置模型。离线阅读、实验、练习、H5P、笔记和板书不要求这些服务。
- 构建有编辑器等资源分块体积提示，没有构建错误；Python 首次初始化仍需读取本地 WebAssembly 运行时。
- 本地存储不是账号云同步或设备级加密。学习数据按浏览器来源和账号隔离，跨设备迁移使用 JSON 备份。
