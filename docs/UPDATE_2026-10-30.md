## 克隆本分支并启动

推荐 Node 24.14.1、Python 3.14.3。私有仓库需要访问权限。Windows PowerShell：

```powershell
git clone --branch codex/ch12-learning-demo https://github.com/yeniwu46-max/plex-interactive-book.git
cd plex-interactive-book
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
$env:Path = "$PWD\.venv\Scripts;$env:Path"
npm ci
npm run check
npm run build
npm run preview
```

打开 `http://127.0.0.1:5190/`；第 12 章地址为 `/read/chapter_divide_and_conquer/index`。开发时使用 `npm run dev`。不要同时启动两个占用 5190 端口的服务。其他系统和后端代理配置见 [复现说明](REPRODUCIBILITY.md)。运行素材随源码与构建脚本恢复，不依赖旧聊天附件；首次安装依赖需要网络。

本次 Git 分支包含源码、锁文件、教材及素材；静态站点通过构建生成，`node_modules`、个人学习记录、会话凭据和临时测试输出不上传。设计概念图用于评审，实际应用使用 Vue 控件，不把概念截图当作交互界面。
