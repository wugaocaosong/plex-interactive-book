## 验证命令

```sh
npm run check
npm run test:e2e
npm run build
```

`check` 包括 Vue / TypeScript 类型检查、内容审计、4 个 Node 测试和 3 个 Python 导入器测试。导入器测试覆盖同名类方法、无法解析符号报错以及字符串 / 注释中的括号。

浏览器测试包括：

1. 在 390×844、820×1180、1440×1000 三种视口下逐节审计 127 个普通阅读小节，验证分页文字守恒、图像加载、公式、标题与内容相邻，以及横向 / 纵向溢出。封面和特殊目录另测。
2. 封面、扉页、星图、全章节文字目录与书签。
3. 全文搜索、图解上一帧 / 下一帧、播放 / 暂停与放大。
4. Python 输出、报错、手动停止、10 秒超时、重置和初始化失败后重试。
5. 全部 73 个被教材引用的独立 Python 源文件执行其真实演示入口，包括二分、排序、链表、树和图。
6. H5P 三道题评分至 3/3、错答重试、刷新恢复、关闭时立即保存与单播放器重开。
7. 跨节、浏览器前进 / 后退、继续阅读、语言偏好、刷新与窗口重排定位。

此外，对静态构建进行了独立实测：打开封面与正文、运行二分查找 Python、打开 H5P 答题并保存 1 分；未发现页面异常或失败资源请求。
