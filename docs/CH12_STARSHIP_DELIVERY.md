# 第 12 章星舰分治实验课：实现与验收

日期：2026-11-05。电子书基线 `68a6318`，分支 `codex/ch12-starship-lab`；配套 PLEX 分支 `codex/ch12-starship-services`。不合并 main，不部署线上。

## 使用入口

进入 `/read/chapter_divide_and_conquer/index` 查看五站路线。12.1、12.2、12.3、12.4、12.6 的正文卡片打开虚拟实验台、即时题和原有编程任务；12.5 提供五题综合自检。浮窗沿用移动、缩放及手机面板。

- 实验：自己操作／观看流程、输入校验、逐步解释、伪代码、速度、暂停及重播。完成记录与观看记录分开。
- 即时题：共 20 题，保留首答、最近作答及提示记录；选择、复选、顺序题在本机判分。
- 编程窗口：真实 Python、测试、终端、运行与测试历史。每任务最近 50 条；版本差异、恢复、撤销恢复、删除和 JSON 导出。停止、异常、超时分别记录。
- 小E：框框阅读 → 框选可见书页或选择当前段落 → 预览图文 → 加入聊天 → 点击发送。代码历史中的“小E复查此版本”绑定不可变快照。输出和诊断按用户选择附带。
- 各小节“共享问答”：登录后提问、回复、点赞、删除自己的内容。离线保留草稿；AI 回复转入讨论前仍需用户确认发布。

## 内容和数据维护

教学脚本见 `CH12_STARSHIP_TEACHING.md`；题目完整清单为 `content/chapter12/quizzes.json`。章节增强入口由 `scripts/chapter12.py` 生成，不手改上游快照。现有五个编程任务 ID、原小节地址和既有图解保留；替换图可展开“查看原图”。

新增 IndexedDB 记录：`chapter12:starship:*`、`chapter12:quiz:*`、`code-history:*`、问答本机草稿。复用账号命名空间和学习备份校验。旧备份无新增字段时采用默认值。截图与会话凭据不进入学习备份；本机运行记录不是服务端正式提交证据。

截图使用 `html-to-image 1.11.13`（https://github.com/bubkoo/html-to-image，MIT），依赖精确锁定；许可证通过 `npm run assets` 收集到 `licenses/dependencies/`。截图渲染为 SVG 后裁切为不超过 2048px 的图像，只采集书页，不采集桌面窗口。截图失败保留文字、LaTeX，可明确选择仅发送文字。

## 运行和配套服务

Node 24+，执行 `npm ci`、`npm run check`、`npm run build`；开发 `npm run dev`，生产静态预览 `npm run serve:dist`。本次验收预览使用端口 5196。正文、实验、测验和本机 Python 不依赖在线模型。

共享 QA 需要配套后端分支、数据库迁移及 `/api` 代理；单独更新电子书不会使旧后端自动支持 QA。后端配置、权限、迁移和接口详见 PLEX 仓库 `docs/2026-11-05-ebook-starship-api.md`。

框框阅读采用服务器环境变量 `EBOOK_VISION_MODEL`、`EBOOK_VISION_API_KEY`、`EBOOK_VISION_BASE_URL`。当前环境未配置模型及密钥，真实视觉联调待验收；没有使用预设回答冒充读图。共享 QA 的两个学生和管理员权限通过隔离数据库测试，不是在线生产账号测试。
