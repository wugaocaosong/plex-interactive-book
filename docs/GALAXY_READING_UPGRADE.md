# 银河书库、阅读交互与代码助手

本轮在 `codex/galaxy-reading-upgrade` 开发，PLEX 后端在 `codex/ebook-code-context` 开发。不合并或覆盖 main，不公开部署。

## 本地使用

使用 Node 24 和 Python 虚拟环境，执行 `npm ci`、`npm run build`、`npm run preview`。开发使用 `npm run dev`，默认端口 5190。教材导入使用 `npm run import:book`；生成资源由构建脚本准备，不依赖聊天附件。原有 PLEX 代理环境变量 `PLEX_API_TARGET` 保持不变，默认 `http://127.0.0.1:5100`。

首页 `/` 为银河书库。一颗星球对应当前可读的 `plex-programming`；另两个席位明确标为待上架，没有虚构内容。点击星球推进，再点击中央封面翻开；继续阅读、返回银河与章节深链接仍可用。WebGL 失败或丢失时降为静态卡片，手动简化模式保存在本机。离开首页销毁场景，隐藏页面停止连续渲染。Three.js `0.187.0`、TresJS `5.10.0` 按需加载；模型、粒子均为本地程序几何，没有外站纹理请求。来源和 MIT 许可见 `licenses/dependencies/` 与依赖锁文件。

阅读区上方的双箭头拖柄可横向拖动，方向键每次 20px、Shift 加方向键 80px、Home 恢复默认。两种阅读模式分别保存宽度；修改后重新分页，沿用内容块定位。窄屏临时约束显示宽度，不覆盖保存偏好。鼠标选字、页边翻页和宽度拖柄独立。

小黑板主工具使用 Lucide 图标，工具名称、快捷键、选中状态及可访问名称保留。画板、绘画数据和窗口位置延续原记录。活动与代码窗口使用同一可拖动、可缩放宿主；窄屏活动窗口占满视口，编辑器不随拖动重建。

## 学习记录与公式

书签菜单可改名称、选择一个分组、录入逗号分隔标签、选择重要程度。颜色仅代表重要程度。分组与重要程度独立管理，删除时保留书签并回落到未分组／普通。旧书签按原定位迁移；缺失创建时间显示“未记录”，不猜测日期。新记录使用稳定 ID。数据进入现有账号命名空间和 JSON 备份；冲突记录沿用原备份导入策略分别保留。

第12章公式保留转换阶段的 `data-tex` 原文，复制默认输出完整 LaTeX；MD 输出带 `$` 或 `$$` 分隔符。复制失败显示可选择的源码。复制控件不计入稳定文本偏移，也不触发翻页。

## 11 个教学场景

原创入口配置在 `content/chapter-enhancements/scenes.json`，导入器在稳定块注册之前应用。上游快照不变，原图可以打开对照。算法模型在 `teaching-models.ts`，活动控件在 `TeachingScene.vue`。

| 章节 | 场景 |
|---|---|
|12|拆分合并、递归二分、前序／中序建树、汉诺塔|
|13|全排列搜索树、N 皇后检查与回退|
|14|爬楼梯、0-1 背包填表和回溯|
|15|分数背包、最大容量双指针|
|16|编辑、运行、错误定位与修正流程|

每个场景初始暂停，支持输入校验、逐步回看、播放、速度、重新播放和解释。到末尾自动停止，关闭和后台隐藏暂停。本机保存输入、步骤、速度，打开后恢复但不自动播放。所有场景均标为教学演示；第16章是预设代码流程，不代表真实安装或执行。原27道练习、5道第12章任务与全书代码保留原身份。

## 角色和代码上下文

`RobotRig.vue` 是基于现有白／青机器人视觉特征重新绘制的原创 SVG 分层角色，头部、身体、眼睛、天线和四肢分别绘制。无需额外角色引擎。真实拖动优先于思考动作，落地后恢复请求状态；答案、取消与失败不修改编辑器。减少动态效果时停止循环动作，保留状态姿态。

代码窗口点击“召唤小E”打开同一桌宠气泡，预览文件、语言、版本与待发送代码；可只发选区。输出与诊断默认不附带。每次发送从当前编辑器重新读取快照，代码不后台上传，快照不进入学习备份。回复标注所分析的版本，不自动修改代码或贴到新的错误行。

后端契约见 `CODE_CONTEXT_API.md`。未配置后端、未登录或旧后端没有确认时明确提示。模拟接口测试与真实模型验收分开记录；本轮不宣称真实在线模型已经联调。
