## 操作与复现

进入 `/read/unit/lab/index` 查看导览，或点击太阳系目录的“星航驿站 · 综合实验”。实验一至四页首选择基础／进阶／挑战；任务卡“动手写代码”打开固定浮窗，关闭回到原处。基础档 7 个卡片可直接运行；进阶／挑战是待完成模板，不把空实现的运行结果记作答题通过。

“更多 → 阅读设置”提供正文字体和沉浸阅读。修改原创内容后执行 `npm run import:book`；原 118 个教材页面及上游快照保持完整。详见 [原创源文件说明](../content/learning/route-lab/README.md)。

```powershell
npm ci
npm run import:book
npm run check
npm run build
npm run dev -- --port 5196
```

导入及检查需要原复现文档要求的 Python 依赖；无新增 npm 依赖或后端接口。新字段包括 `ReaderPreferences.labLevel/font/immersion`、原创代码来源与原草稿标识，以及 `lab-run:<key>` 运行反馈；旧备份使用默认偏好，继续保留原记录。数据库及 JSON 备份版本不变。
