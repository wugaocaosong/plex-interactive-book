# 三扇舱门：直觉可靠吗？——v0.4 逐页深化脚本

45 分钟由七环节组成：学习起点 3、三门挑战 7、拆解直觉 8、Python 补学 10、批量实验 7、编程与测验 8、回顾 2。学生可跳过或返回；逻辑页地址保持不变，字号影响物理分页。

| 页／地址尾部 | 目标与活动 | 观察证据／教师追问 |
|---|---|---|
| 1 start | 查看七环节路线、自愿自评、继续上次活动 | 哪个概念需要补学？访问数量不是成绩。 |
| 2 rules | 固定初选和核心，勾选全部合法开门选项 | 两个排除条件必须同时满足；初选正确时允许两扇空门。 |
| 3 choose | 选择一扇舱门 | 无信息时任意选择；不要猜隐藏核心。 |
| 4 predict | 留下预测和可选理由，小E开空门，再决策揭晓 | 首次预测永久保留。一次输赢能说明策略优劣吗？ |
| 5 cases | 改变初选，枚举三个核心位置和两种策略结果 | 正确初选的一行可有两种主持人动作，各占 1/6。 |
| 6 explain | 分步加入主持人条件，比较初选正确／错误 | 换门获奖恰好对应初选错误；结论依赖经典主持人规则。 |
| 7 variables | 运行并修改赋值、比较、获奖及频率示例 | 改 final，解释 `=` 和 `==`；分母为零如何处理？ |
| 8 conditions | 运行合法门列表，尝试 and / or | 两个条件应同时满足；输出编号 0、1、2 对应舱门 1、2、3。 |
| 9 repeat | 固定种子运行十次随机选择 | 同种子可复现，不代表某个种子更幸运。 |
| 10 single-run | 真实运行一次 Python，核对记录与舱门状态 | opened 不等于 first / prize，switch 排除 first / opened。 |
| 11 compare | 预测后运行四档次数，查看精确频率、完整曲线、回放 | 理论线固定，实际频率会波动；不保证每一步误差缩小。 |
| 12 practice | 原三题填空、修错、策略修改，测试与分层提示 | 错误分别回变量、条件、循环补学；在线提交由服务端核验。 |
| 13 quiz | 原四道 H5P，自查主持人、初选、波动、策略 | 可重试。报告将未答对项链接回对应页。 |
| 14 reflection | 对照首次预测、写解释、预览下载或打印报告 | 不自动语义评分反思；三题通过＋自测至少三题且规则题正确才满足达成条件。 |

小E短提示默认收起，逐层展开为离线教学提示；主动提问才访问 PLEX。板书每页独立，概率模板可拆分擦除、撤销；动画、板书、代码及 H5P 不放进翻页克隆容器。普通翻页不替换当前实验，显式“下一教学环节”才保存并切换。

参考仍为 [Think Python 第三版](https://greenteapress.com/wp/think-python-3rd-edition/) 的入门概念组织与 [Illinois 三门问题说明](https://discovery.cs.illinois.edu/guides/Classic-Problems/Monty-Hall-Problem-Interactive-Game-and-Solution/)。本单元中文讲解、场景和模板为 PLEX 原创，未导入另一整本教材。
