# v0.4 三门样板课深化：技术总结

本版沿用 14 个逻辑页及原地址，118 个上游教材页、11 个 PLEX 附页、27 道编程题、两套 H5P 保持原身份。新增内容不写入上游快照。本机教学活动与真实在线模型明确分开。

## 教学定义与活动联动

`content/learning/monty_lesson.py` 保存七环节、逐页目标、活动、小E提示、下一页及服务端题目引用；`monty.py` 保留原正文、三道评分题及 H5P 题目。`import:book` 生成正文入口，`build:learning` 生成单元元数据与三个不计分补学示例。详见 [逐页深化脚本](LESSON_MONTY_V04.md)。

`Layout.vue` 管理书籍定位与固定活动宿主。普通翻页保留已打开的活动，只更新“转到本页活动”；显式切换先调用 `flushLearning`，卸载旧活动，终止它拥有的 Worker，再定位并打开目标页活动。移动端关闭活动返回原文，桌面共用原可调整分栏。其他活动放在可展开菜单中。

`UnitPanel` 分别记录访问、完成活动及评分结果。规则判断正确、完成故事、枚举自查、解释推演、实际 Python 返回成功分别写入活动记录；H5P 完成事件和三题通过另记。访问页数与故事输赢不用于推断掌握。报告达成条件仍是三题通过、四题自测至少三题正确且规则题正确。

## 二维场景与概率模型

`monty-hall.ts` 负责所有规则及确定性状态转换。选择、开门、决策与下一轮都有阶段保护，重复操作不会再次记录。首次预测默认空白，明确提交或跳过后才开门；首次理由保留，之后修正另记。旧数据没有首次预测时显示“未记录”，不会把旧的最近预测猜成首次。

`MontyScene.vue` 使用 Motion for Vue，只渲染模型状态，不抽奖、不判题。回看不修改原模型；动画可跳过，并监听减少动态效果设置。揭晓前不渲染核心元素或暴露核心位置的替代文字。板书快照同样只绘制当时允许公开的状态。

`MontyReasoning.vue` 的规则、枚举、解释状态与随机故事分开保存。每个核心位置概率为 1/3；初选正确时两种合法开门路径分别为 1/6，不算成四种等概率情况。全部合法状态的加权理论结果由纯模型测试验证。

## 实际 Python 与图表

保留模块 Worker、初始化 90 秒、整次执行 10 秒、运行 ID 和终止重建机制。新增独立单次入口，批量继续提供 10、100、1000、10000 次。每个结果校验次数、种子、全部门状态、策略获奖判断及汇总一致性，再进入图表和报告。失败或停止不生成成功记录；最新有效结果单独保留。

`FrequencyChart.vue` 按需注册 ECharts 的折线、坐标、图例、提示、参考线、无障碍与 SVG 模块。每条实际记录都进入累计曲线，不平滑、不抽样。文字表格、任意累计位置数值、记录回放和 SVG 下载并存。Vue ECharts 观察容器大小；图表随阅读主题变化。三个补学示例复用 CodePanel，草稿按独立稳定 ID 保存，不进入 27 题评分。

## 几何板书、报告与数据迁移

板书 version 2 在旧笔画、文字和三门快照外新增矩形、椭圆、箭头；保存几何参数和固定 Rough.js 种子。概率分组模板由六个普通对象组成，支持同样的橡皮、撤销、重做和 PNG 导出。SVG 路径由同一份数据重建，刷新与导出不重新抽取绘制风格。

UnitProgress version 2 新增活动首次完成时间、最近活动定位、按页提示层数。JSON 备份 version 3 继续接受 1、2。迁移仅补结构，不补造历史成绩、首次理由或时间；重复迁移无变化。账号命名空间、访客复制、冲突保留规则不变，旧版源记录保留。

`lesson-report.ts` 从现有证据构建白名单报告，没有第二套成绩存储。报告包含首次预测、最终解释、最近有效模拟、三题及四题结果、提示及固定补学映射。HTML 将用户文本转义、内嵌实际曲线 SVG 和打印 CSS，不依赖字体/CDN/脚本；Markdown 提供原书链接。默认无姓名、账号、令牌或在线对话。预览后方可下载或打印；浏览器打印功能可保存 PDF。

## PLEX 与开源资源

保持 v0.3 接入基线与注册脚本，未新增公共 API 或数据库迁移。规则和主持人条件关联 MH030002，变量与频率关联 MH030001，换门与循环关联 MH030003。发送前展示关联题目和问题，服务端仍核验题目版本、正式作答与报错运行记录。预设提示不会冒充模型结果。

新增固定依赖：motion-v 2.8.0 / @vueuse/core 12.8.2（MIT）、echarts 6.1.0（Apache-2.0）、vue-echarts 8.3.2（MIT）、roughjs 4.6.6（MIT）；测试依赖 @axe-core/playwright 4.14.0（MPL-2.0）。源码来源见用户方案对应官方仓库，完整许可证由 `prepare-assets.mjs` 收集到 `licenses/dependencies` 并随静态站点提供。Motion 和 ECharts 随活动异步加载；没有新增外站运行请求。

## 复现与已知边界

安装与静态运行继续遵循 [REPRODUCIBILITY.md](REPRODUCIBILITY.md)，PLEX 设置见 [PLEX_INTEGRATION.md](PLEX_INTEGRATION.md)。ZIP 含源码、锁文件、完整静态运行资源及逐文件哈希，不含 node_modules、账号会话或本机学习数据库。

自动化结果见 [v0.4 验收报告](VALIDATION_V04.md)。人工 45 分钟课堂试用及 NVDA / VoiceOver 走查仍需独立验收；不能由 axe 代替。自由绘画需要指针操作，另提供键盘文字、图形和模板插入。

固定的 Vue/VitePress 旧版本依赖仍有 npm 公告：Vue SSR 属性名过滤、Vite/esbuild 开发服务器及 KaTeX 前置原型污染相关问题。本轮按方案保留 Vue 3.5.22 / VitePress 1.6.4，未用强制升级改变框架。交付为可信教材的本机静态成品，没有运行时 SSR，也不接收外部 Markdown 编译；开发服务仅绑定 127.0.0.1。详细审计快照另存，不宣称依赖零漏洞；后续框架升级应单独回归。
