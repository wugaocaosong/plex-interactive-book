# v0.2 学习工具技术总结

日期：2026-10-23。开发目标是在同一份教材上形成阅读、预测、实验、编码、反馈、记录的学习流程。保留上游固定版本与全部 129 个书籍小节，不引入账号或服务端。

## 结构与内容

VitePress 1.6.4 / Vue 3.5.22 提供路由与宿主，StPageFlip 2.0.7 提供纸页效果；H5P 仍承载原有三道二分查找题。CodeMirror 6 用于 Python 编辑，Shiki 2.5.0 用于其他语言只读高亮，Pyodide 314.0.7 保持模块 Worker。新增依赖以精确版本写入 package.json 和锁文件，许可通过 assets 命令归档。

阅读器控制器管理内容加载、当前位置、页面窗口、面板与记录。StudyReader 管理连续正文及最多五节的滚动窗口，分页器管理 HTML 到纸页的内容守恒。CodePanel、LearningHub 和 H5P 在翻页 DOM 之外按需加载，避免单页翻书的克隆影响 Vue 状态。

翻书时预排当前及相邻小节；翻页动画结束后再移动页面窗口与同步路由。JSON 和排版缓存有数量上限。章节之间按桌面跨页对齐，奇数页末尾的空白背页不复制正文。加载目标小节失败时保留当前页面并显示重试。学习模式补入前一节时补偿滚动高度，移除远处小节时保持当前可见位置。

字体、图片、图解、Python、H5P 和练习资源随静态构建提供。源码中不保存个人浏览器数据。

## 稳定内容身份与批注

原始教材快照不修改。导入器把生成后的顶层内容块交给 block_ids 注册表，以原文指纹、所属标题和相邻关系复用身份。多义匹配不猜测，生成新身份并报告。首次迁移保留 b0 等旧编号及 activity 的别名。代码示例身份由章节、源文件和符号产生，不再取决于引用顺序。

必须提交 `content/block-registry.json`。删除它后无法保证后续版本继续沿用历史身份。`docs/block-migration-report.json` 是最近一次导入的新增／歧义报告，无变化时为空。

批注保存起止稳定块 ID、块内偏移、exact/prefix/suffix 引用、内容版本和时间。定位先验证原块，再查找引用与上下文；只有唯一匹配才迁移，否则显示待定位。跨段落引用由源内容重建，避免把页眉页脚纳入笔记。KaTeX 的显示 DOM 会重复数学文本，因此额外保留原始 TeX 作为逻辑坐标段；标注不修改公式内部。

高亮、划线与批注作为内容装饰参与排版，原文和引用不会被改写。公式、图片与代码使用块级笔记。Markdown 导出包含引用、笔记及原文链接；JSON 备份保留完整结构。

## 本地数据与兼容

IndexedDB 数据库 `plex-learning` 的 records 仓库保存版本化记录：阅读偏好、reading、bookmarks、annotation、draft、attempt、lab 和 H5P。旧 `plex:*` localStorage 数据仅迁移一次，旧值保留；同步的小型阅读设置继续写入 localStorage 供兼容读取。

Vue 响应式对象不能直接进行 IndexedDB / Worker 结构化克隆。写入和提交测试前先转换为普通可序列化数据，这一点已通过浏览器流程验证。

草稿按示例／练习 ID、语言和起始源码版本区分；500ms 防抖保存，失焦、切换或卸载面板前立即写入。重置保留一个可撤销副本。存储失败通过可见提示报告，不能把失败当成已保存。

备份格式为 plex-learning/version 1，限定书籍标识并在导入前验证。导入界面展示条数；相同记录合并，内容不同的版本放入 conflict 记录。用户可导出冲突版本或采用其中一个，原版本仍被保留。浏览器、域名或端口不同属于不同存储来源，需要通过 JSON 迁移。

## 教学实验与练习

六个主题包含 16 个可选择模型：数组、单链表、栈、队列、二分、冒泡／插入／快排、树的四种遍历、图的 BFS／DFS、阶乘／斐波那契。算法状态由纯 TypeScript 函数产生，步骤保存数组／节点／边、活动位置、变量、操作计数、代码行及解释。

每个关键步骤先显示预测，再给反馈；自动播放在未回答的预测点停止。模型有输入上限及边界校验，循环图使用已访问集合。递归显示调用栈与调用次数。这里的高亮只对应预设教学代码，不宣称是用户编辑代码的执行轨迹。

24 题源内容在 `content/learning/exercises.py`，每组各一题填空、修改、修错、独立实现；共 112 个测试用例。题目采用 `solve` 函数返回值接口，树和图使用题面注明的 JSON 数组编码。三个提示层次为思路、关键步骤、完整参考解法。普通源码示例仍执行真实 `__main__` 入口。

Worker 协议包含 requestId/runId、init/run/check、ready/stdout/stderr/done/result/error。迟到结果按运行 ID 丢弃。初始化最多 90 秒，执行或整次判题最多 10 秒；停止后终止 Worker，下次重建。判题使用独立 Worker，各用例创建新命名空间并复制输入，防止一个用例改写后续输入。运行错误返回文件、行列和 traceback，测试逐例显示输入、期望、实际结果与异常。

全部代码和用例在客户端，这是一套自学反馈工具，不作为有保密试题要求的考试判分服务。

术语原表只有翻译；新增的 128 条解释为 PLEX 编写，独立维护在 glossary.tsv，并关联正文。新增学习资产的构建检查不会写文件；生成操作使用 build:learning。

## 维护与复现

1. 安装锁定 Node 和 Python 依赖，执行 `npm run check`。
2. 修改教材适配时执行 `npm run import:book`，检查注册表与迁移报告；重复导入应无差异。
3. 修改练习或术语后执行 `npm run build:learning`；修改实验模型后运行 `npm test`。
4. 执行 `npm run build`、`npm run test:e2e`，按需用 PLEX_TEST_PREVIEW=1 检查构建成品。
5. 提交所有源码和文档后执行 `npm run package`。包包含源码、资源、成品、启动脚本、逐文件清单和 SHA-256，不包含依赖目录或个人记录。

验证详情见 `VALIDATION_V02.md`。浏览器检查包含内容、实际操作和错误恢复；屏幕阅读器实机结果与自动化结果分别记录，不能互相替代。
