# 摄像头、翻页笔与离线语音

日期：2026-10-30。分支：`codex/ch12-learning-demo`。全书共用，重点用于第 12—16 章；不更改 PLEX 后端。

## 使用方法

启动后打开“更多 → 翻页控制”。首次开启摄像头或麦克风，需要在浏览器中允许权限；建议在 Windows Chrome/Edge 的 `http://127.0.0.1:5190/` 使用。普通远程 HTTP 来源不支持媒体权限，应使用 HTTPS。

1. **USB 翻页笔**：点击“录入上一页”或“录入下一页”，按实体设备，查看 `key/code`，再确认映射。在测试区按键只显示结果，不翻正文。默认 PageUp/PageDown 和左右方向键可用。HID 键盘名称不能证明设备已映射；若无事件，检查焦点、接收器和设备电源。按住不重复翻页，编辑器和弹窗内不翻背景。
2. **摄像头**：选择设备并开启，确认镜像预览出现。关闭设置，单手张掌稳定片刻，向左挥下一页、向右挥上一页；回手后先停稳。可反转方向、调灵敏度、收起预览或停止。两只手同时入镜时不触发。
3. **语音**：选择麦克风并开启，等待“离线聆听中”，关闭设置。说“上、前、上一页、前一页、往前、向前翻”，或“下、后、翻页、下一页、后一页、往后、向后翻”。只接受明确指令，不用任意子串匹配；“上下文”“上海”不触发。存在方向冲突时重说。单字识别受收音和环境影响，课堂使用优先说完整的“上一页／下一页”。

翻书模式沿用 StPageFlip；连续模式滚动正文容器高度的 85%，到边界加载相邻小节。章节目录仍按稳定地址跳转。到书籍首尾不循环。鼠标拖拽、触屏与既有按钮继续可用。

设置和活动弹窗、文字输入或选区存在时不翻背景；关闭浮窗后清空旧识别结果。页面进入后台或失去焦点时释放摄像头和麦克风，返回后需重新开启。刷新默认关闭两者，不恢复监听。

## 运行资源与复现

- `@mediapipe/tasks-vision 0.10.32`：本地 WASM 与 hand_landmarker 模型。该版本的加载器使用 `importScripts`，因此手部检测使用独立的经典 Worker；Python 的模块 Worker 保持不变。
- `vosk-browser 0.0.8`：本地中文模型 `vosk-model-small-cn-0.22`，AudioWorklet 单声道采集并连续重采样至 16 kHz，Vosk 内置 Worker 解码。无浏览器云语音服务和外部 CDN 请求。
- `content/input-models/manifest.json` 固定上游地址、原始/转换后 SHA-256、大小和许可。模型直接随源码保存，日常安装和构建不再下载模型。
- `npm ci` 后按原复现说明设置 Python 虚拟环境；`npm run assets` 校验并复制模型、WASM 和运行脚本，`npm run build` 将其放入静态成品。已有 ZIP 打包流程同时包含 Git 跟踪源码与完整静态资源。
- `python scripts/prepare-input-models.py` 校验资源；加 `--download` 可从固定上游重新构建。Vosk ZIP 转为固定时间戳的 USTAR/GZIP，目录权限为 0755、文件为 0644；目录条目不能省略，否则 Vosk 的缓存同步失败。

Vosk 默认将模型缓存到本机 IndexedDB。音频和摄像头帧只在本机内存中处理，不上传或保存。本机模型缓存与学习记录独立；摄像头/麦克风设备选择保存在本机设置中，不随学习备份迁移。

## 控制与状态接口

`PageTurnCommand` 包含方向、来源、会话和事件编号。公共入口处理重复消息、输入焦点、选区、弹窗、动画及加载阻塞；阻塞期间丢弃命令，不排队补翻。`ReaderControlPreferences` 保存按键、灵敏度与方向；使用原学习数据库及账号命名空间，JSON v3 备份自然包含该记录，旧备份缺失时采用默认值。

张掌检测依据四指展开及手掌中心轨迹；标准阈值为稳定 200ms、150—900ms 内水平位移 20%、横向至少为纵向两倍，冷却 900ms。低/高灵敏度位移分别为 28%/14%。模型检测至多两只手，用于明确拒绝多人或双手干扰，每次只允许一帧在途。

语音只响应最终结果，浮窗切换时新建识别器并拒绝旧代结果。停止时释放流、AudioContext、音频节点与 Worker。固定版本 Vosk 在加载失败前的 `terminate()` 会访问未初始化模型；适配层通过其 Worker 句柄立即终止，升级 Vosk 时必须回归加载中取消、失败重试与停止。
