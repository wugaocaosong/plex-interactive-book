# PLEX · 星轨编程

**Python 与算法的探索之旅**

面向编程入门的交互式数字教材，以 PLEX 为主题延伸，使用 HTML5 等 Web 技术实现可交互电子书。以章节阅读为主线，将算法动画、可运行代码和即时练习嵌入正文。

## 项目范围

本仓库独立用于数字教材创作与阅读体验开发。首期重点为电子书内容组织、星轨主题视觉、交互演示与 Python 学习体验。

- 正文来源：[krahets/hello-algo（Hello 算法）](https://github.com/krahets/hello-algo)，计划按原文引入并保留来源与署名。
- 主题：星轨、行星、宇航员与探索旅程。
- 书名：星轨编程；副标题：Python 与算法的探索之旅。
- 载体：适配桌面、平板与移动端的 H5 交互式电子书。
